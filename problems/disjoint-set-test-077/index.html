The key move

Disjoint set union

Maintain connected components with parent representatives, merging sets as relationships are added and querying representatives to test connectivity.

    6int find(int x) {
    7    if(parent[x] == x) return x;
    8    return parent[x] = find(parent[x]);
    9}
    10void unite(int x, int y){
    11    x = find(x); y = find(y);
    12    if (rk[x] > rk[y]) {
    13        parent[y] = x;

    15        parent[y] = x;
    16    } else {
    17        parent[y] = x;
    18        rk[x]++;
    19    }
    20}

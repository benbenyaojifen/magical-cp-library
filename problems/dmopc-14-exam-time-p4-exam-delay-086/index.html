The key move

Shortest paths

Build a weighted graph, repeatedly expand the closest known state with a priority queue, and relax outgoing edges whenever a shorter route is found.

    22         auto[w, e, u] = pq.top(); pq.pop();
    23         if (u == n) break;

    31                dist[v].second = e + 1;
    32                pq.emplace(dist[v].first, e + 1, v);
    33            }
    34         }
